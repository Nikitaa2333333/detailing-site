# Чат-консультант: прокси на Google Apps Script

Сайт статичный, а ключ модели в код страницы класть нельзя. Поэтому между сайтом и моделью
стоит бесплатный скрипт Google: браузер шлёт ему переписку, он добавляет ключ и пересылает
её в Groq. Заявки из чата скрипт пишет в Google-таблицу, лист «Заявки чата».

```
браузер (dssever.ru) ──► Apps Script (ключ) ──► Groq
   инструменты: поиск машин, услуг, цены — здесь, на модулях калькулятора
```

Модель видит цены только в ответах инструментов, сумму считает код: придумать цену ей негде.

## Включить (5 минут)

1. **Ключ Groq.** console.groq.com → API Keys → Create API Key. Скопировать `gsk_…`.
   Регистрация из России может потребовать VPN; посетителям сайта VPN не нужен.
2. **Таблица.** Создать Google-таблицу (например, «DS SEVER — заявки»). Меню
   **Расширения → Apps Script**.
3. **Код.** Стереть всё в `Code.gs`, вставить содержимое [Code.gs](Code.gs), сохранить.
4. **Ключ в свойства.** Слева шестерёнка «Настройки проекта» → внизу «Свойства скрипта» →
   добавить `API_KEY` = `gsk_…`. Сохранить.
5. **Опубликовать.** Кнопка **Начать развёртывание → Новое развёртывание** → тип
   «Веб-приложение». Выполнять от имени: **Я**. Доступ: **Все**. Развернуть, разрешить
   доступ к таблице. Скопировать URL вида `https://script.google.com/macros/s/…/exec`.
6. **Проверка.** Открыть этот URL в браузере — должно быть `{"ok":true,…,"key":true}`.
7. **Сайт.** URL — в `CHAT_URL` в [.github/workflows/deploy.yml](../../.github/workflows/deploy.yml),
   push в `main`. На всех страницах появится кнопка «Рассчитать в чате».

Поправили `Code.gs` — вставить заново и **Управление развёртываниями → карандаш → Версия:
новая**. Новое развёртывание вместо этого даст новый URL.

## Настройки (Свойства скрипта)

| Свойство | По умолчанию | Что это |
|---|---|---|
| `API_KEY` | — | ключ провайдера, обязательно |
| `MODEL` | `openai/gpt-oss-120b` | модель |
| `API_URL` | Groq | адрес `…/chat/completions` |
| `EXTRA` | `{"reasoning_effort":"low"}` | добавка к запросу; для не-gpt-oss моделей поставить `{}` |
| `MAX_TOKENS` | `2000` | потолок ответа |
| `DAILY_LIMIT` | `800` | запросов к модели в сутки на весь сайт (одно сообщение человека ≈ 2–3 запроса) |

Другие модели Groq: `moonshotai/kimi-k2-instruct`, `meta-llama/llama-4-scout-17b-16e-instruct`
(выше лимит токенов в минуту), `llama-3.3-70b-versatile`. Для них `EXTRA` = `{}`.

Сменить провайдера — те же три свойства, код не трогаем. Gemini:
`API_URL` = `https://generativelanguage.googleapis.com/v1beta/openai/chat/completions`,
`MODEL` = `gemini-2.5-flash`, `EXTRA` = `{}`, ключ из aistudio.google.com.

## Ограничения бесплатного тарифа

- Лимит токенов в минуту: при нескольких людях сразу чат может отвечать с паузой или
  «Консультант сейчас не отвечает». Скрипт сам повторяет запрос дважды.
- `DAILY_LIMIT` защищает ключ: адрес прокси виден в коде страницы.
- Ответ идёт 2–6 с (скрипт Google + модель), без печати по буквам.

## Проверить локально, без Apps Script

```powershell
cd akb-bu
$env:CHAT_API_KEY = 'gsk_...'; node chat-proxy/dev.mjs    # прокси на :4331, ход модели — в консоль
# в другом окне:
$env:CHAT_URL = 'http://127.0.0.1:4331'; npx astro dev --host 127.0.0.1 --port 4321
```
